# AIbrowse 0.1.1 Windows x64 内部开发候选

本候选用于内部开发与验收，未签名，采用手动升级，不提供自动更新或公开 Release。
Stage7 最终验收仍在进行；本文件随最终机器证据及新独立阶段审核更新，不提前宣告阶段完成。

## 安装与升级

安装、升级和卸载需要 Windows UAC，程序固定安装到 `C:\Program Files\AIbrowse`。
应用以普通用户运行，各用户的业务数据、浏览器会话和 DPAPI 凭据仍按用户隔离。
升级前应退出应用；程序或 guardian 仍占用时，安装器拒绝操作并保留原现场，不强制结束应用。
卸载保留 userData 和安装目录中不属于本程序的文件。重新安装后可继续读取保留的数据。

## 本轮变化

- 本地数据入口提供 Sources、Research、Watch 与保存对话的备份和恢复；恢复经过完整验证、维护态关闭与重启，旧动作不会重放。
- 超过物理容量或无法验证的数据被拒绝，原件与恢复路径保留；三库迁移、维护态及中断恢复具有独立验证。
- 网页崩溃可以单独恢复，应用界面崩溃及主进程错误经过受控关闭，业务写者和子进程按生命周期退出。
- 诊断先生成有界、脱敏预览，由用户选择保存；预览取消和维护态错误提供中文提示。
- 会话临时文件保护使用精确的 64 位文件身份，避免 NTFS 标识被浮点舍入后误接纳另一文件。
- 发行包固定依赖、资产白名单、Electron fuses 和 ASAR 完整性，构建清单记录来源及实际产物摘要。

## 数据与权限说明

备份包含本地私密正文，应妥善保管；备份不包含 API Key、Provider 配置或 Cookie。
三个业务库在本地以明文保存，凭据使用 Windows DPAPI；本版本不提供备份加密、云同步或退出后的后台监控。
恢复替换三个业务库和保存对话，会关闭当前标签页并重新启动应用；恢复前可先备份当前数据。
AI 通过受限工具操作浏览器，无任意系统、文件、SQL 或脚本执行权限。网页和模型内容仍属于不可信输入。

## 验证覆盖与限制

用户已批准同机受控首装、手动升级、卸载、重装及实际包检查替代独立 Windows 环境验收，
并接受其它 Windows 配置与缺少开发依赖的独立机器未实测的兼容风险。独立 Windows 保持 **NOT RUN**。
电池续航及拔电条件保持 **NOT RUN**；外部 Provider 的本轮性能测量因凭据不可用保持 **NOT RUN**。
CI 配置仅产出内部 artifact、无公开发布权限；本轮实际 CI 保持 **NOT RUN**，不将本地构建冒充 CI 成功。

最终交付前必须补齐实际原生恢复、通知、安装矩阵、性能长测、两次洁净构建及新独立阶段审核。
最终产物与源码 commit、版本、摘要的对应关系以实际构建清单和 `doc/tasks/progress.md` 的有效证据索引为准。
